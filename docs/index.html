Features

Built different

Every feature is designed around transparency and speed

Mirror-powered speed

A single mirror.json file feeds the entire store. Version numbers, sizes, and download links are pre-fetched by GitHub Actions — so the client never touches GitHub's API.

Zero trackers

No analytics, no telemetry, no ad SDKs. Your data never leaves your device.

No rate limits

Works 100% free out of the box. Power users can add a GitHub token to jump from 60 to 5,000 requests/hour.

Custom profile

Pick your name and one of four hand-drawn avatars — all rendered on Canvas, no image assets required.

VirusTotal integrated

Every app detail links directly to a VirusTotal scan of the exact APK. One tap, 70+ antiviruses.

13+ themes

Dark, Light, AMOLED, Ocean, Cyberpunk, Forest, Sunset, Sakura, Dracula, Nord, Coffee, and more.
